# 🧑‍💻 Basic Personal Portfolio

This is a simple and responsive personal portfolio website for myself. The website presents personal information, educational background, skills, project links, and personal mission and vision statements using clean HTML and CSS.

🔗 **Live Site:** [https://slightsmile.github.io/Basic-Portfolio/](https://slightsmile.github.io/Basic-Portfolio/)

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage  
- **CSS3** – Styling, layout, and responsiveness

---

## 📁 File Structure

- [`index.html`](index.html): Main HTML file containing the website structure and content.
- [`styles.css`](styles.css): CSS file for styling and layout.

---

## 🚀 Getting Started

To run this project locally:

1. Clone or download this repository.
2. Open `index.html` with any modern web browser to view the portfolio.

---

## ✏️ Customization

- Update text content in `index.html` (e.g., bio, education, projects).
- Replace `Picture.jpg` with your own profile image.
- Modify `styles.css` to personalize fonts, colors, layout, etc.
